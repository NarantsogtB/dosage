## 4c. ЭМЯ-ны удирдамж — бодит хэмжээ, бодит зардал

ЭМХТ-ийн жагсаалтыг бүтнээр нь шалгалаа. Тоо баримт:

- Нийт ~100 эмнэлзүйн заавар нийтлэгдсэн
- Үүнээс **хүүхдэд хамааралтай нь ~14**
- Үүнээс эмийн тунгийн мэдээлэл агуулах магадлалтай нь **~10**

Өөрөөр хэлбэл 50 эмийн **10–15 нь л** ЭМЯ-ны баримтаар батлагдана. 50 бүгд биш.
Энэ хүлээлтийг эхнээс нь зөв тавих нь чухал.

### Техникийн бэрхшээл (туршиж шалгасан)

| Файл | Агуулга | Үр дүн |
|---|---|---|
| `a-56.pdf` Хүүхдийн яаралтай тусламж | скан зураг | ❌ текст гарахгүй |
| `a-37.pdf` Уушгины хатгаа | скан зураг | ❌ текст гарахгүй |
| `a-46.pdf` Астма | скан зураг | ❌ текст гарахгүй |
| Аминдэм, эрдсийн бэлдмэл (тушаал) | текст, гэхдээ хуучин кодчлол | ⚠️ гараар засварлана |

**Автомат задлах боломжгүй.** Энэ бол гараар унших ажил — баримт бүрт
30–60 минут. 10–14 баримт ≈ **1.5–2 өдөр**. 2 долоо хоног биш.

### Линкийн эрсдэл — заавал шийдэх

hdc.gov.mn дээр илэрсэн бодит асуудлууд:

- Нэг `A130.pdf` файл **гурван өөр зааврын** линк болж байна (астма, хатгаа, УАБӨ)
- Ижил заавар өөр өөр нэрээр давхардсан (`a-15`/`a-71`, `a-19`/`a-70`, `a-21`/`a-72`)
- Файлын нэр тогтворгүй (`a-31_7ihzepu.pdf`, `yas_W0uCF2o.pdf`)

**Шийдэл: hdc.gov.mn-ийг live эх сурвалж болгож холбохгүй.** PDF-ийг өөрсдөө
архивлаж, SHA-256 hash хадгална. Тушаалын дугаар, огноог `SourceRef`-д бичнэ.

### Тэргүүлэх дараалал (2 өдөрт багтаана)

**Эхний ээлж — хамгийн өндөр өгөөж (5 баримт):**

| Баримт | Ямар эмд нөлөөлөх | Яагаад эхэнд |
|---|---|---|
| `a-56` Хүүхдэд үзүүлэх яаралтай тусламж | adrenaline, atropine, diazepam, midazolam | **V5 Emergency mode-ийн суурь** |
| `a-37` Уушгины хатгаа | amoxicillin, ampicillin, gentamicin | Хүүхдийн №1 антибиотик |
| `a-46` Астма | salbutamol, prednisolone, ICS | Өндөр давтамжтай |
| `a-32` Бөөр шээсний замын халдвар | cefixime, co-trimoxazole | UTI бол хүүхдэд түгээмэл |
| Аминдэм, эрдсийн бэлдмэл (тушаал) | vitamin A, vitamin D | **Аль хэдийн текст задарсан** |

Аминдэмийн тушаалаас гарсан бодит утга (жишээ):

- Vitamin A: 6–11 сар → 100,000 ОУН; 12–59 сар → 200,000 ОУН, 4–6 сар тутам
- Vitamin D: нярай 400 ОУН/өдөр; 1–18 нас 600 ОУН/өдөр
- Дээд хязгаар: <6 сар 1,000 ОУН; 7–12 сар 1,500; 1–3 нас 2,500; 9–18 нас 4,000

**Хоёрдугаар ээлж (5 баримт):** чих хамар хоолой (дунд чихний үрэвсэл →
amoxicillin өндөр тун), сүрьеэ, гэдэсний бактерит халдвар, нярайн шарлалт,
арьсны мөөгөнцөр/атопийн дерматит.

**Алгасах:** насанд хүрэгчдийн заавар (гипертензи, чихрийн шижин, элэгний
цирроз г.м.) — ~85 баримт. Хүүхдийн calculator-т хамааралгүй.

### Хэн ч дурдаагүй, гэхдээ хамгийн өндөр өгөөжтэй баримт

**Эмийн үндэсний жагсаалт** болон **ЭМД-ын хөнгөлөлттэй эмийн жагсаалт**
(ЭМДҮЗ-ийн тушаал). Эдгээр нь:

- Сайдын/зөвлөлийн тушаал = хууль ёсоор хүчинтэй, шалгах боломжтой
- 5–10 биш, **олон зуун эм** хамарна
- Монголын эмч **бодитоор юу бичдэгийг** харуулна (хөнгөлөлт нь жор бичихэд
  шууд нөлөөлдөг)

Энэ нь "дараагийн 50 эмээ юу байх вэ?" гэсэн асуултад analytics-аас өмнө,
илүү найдвартай хариулна.
