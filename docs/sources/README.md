# Эх сурвалжийн стратеги — индекс

> Эмийн тунгийн өгөгдөл хаанаас ирэх, хэрхэн баталгаажих, ямар эрх зүйн
> хязгаарлалттай. Өгөгдлийн төрлийн жинхэнэ эх: `lib/domain/source.ts`.
> Эх сурвалжийн бүртгэл: `lib/data/sources/registry.ts`.

**Гол зарчим:** Тоо зохиохгүй. Тоо бүр эх сурвалжтай. Эх сурвалж бүр шалгах боломжтой.
