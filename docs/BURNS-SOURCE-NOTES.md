## 1. Гадаргуугийн талбай

### Естийн дүрэм — х.41, Зураг 4 ✅ ХЭРЭГЖСЭН

| Бүс | Хүүхэд | Насанд хүрэгч |
|---|---|---|
| Толгой | 19% | 9% |
| Дээд мөч (тус бүр) | 9% | 9% |
| Их бие урд | 18% | 18% |
| Их бие ар | 18% | 18% |
| Доод мөч (тус бүр) | 13% | 18% |
| Бэлэг эрхтэн | 1% | 1% |

Хоёулаа нийлбэр 100%. `lib/data/burns/rule-of-nines.ts`-д хэрэгжсэн.

### Нарийвчилсан хувилбар — х.49

Насанд хүрэгчид: гар тус бүр 9%, хөл тус бүр 18%, их бие урд 18%,
их бие ар 18%, **толгой 7%, хүзүү 2%**, сарвуу/тавхай/цавь тус бүр 1%.

Толгой+хүзүү = 9% буюу х.41-ийн утгатай нийцнэ. Хүзүүг тусад нь
задалсан хувилбар.

### Алганы дүрэм — х.49

| Хэмжилт | Утга |
|---|---|
| Алга + хуруу (ерөнхий) | ≈1% (0.78% ± 0.08%) |
| Эрэгтэй, зөвхөн алга | 0.5% |
| Эмэгтэй, зөвхөн алга | 0.4% |
| **Хүүхэд, алга + хуруу** | **0.92%** |
| **Хүүхэд, зөвхөн алга** | **0.52%** |

⚠️ Одоогийн код `PALM_PERCENT = 1` гэж бичсэн. Хүүхдийн утга 0.92%
буюу арай өөр — нарийвчлах эсэхийг шийдэх.

### ⚠️ Lund-Browder-ийн A/B/C хүснэгт НОМД БАЙХГҮЙ

х.41 «Ланд, Броудер нарын хүснэгтийг ашиглана» гэж **зөвлөсөн** боловч
хүснэгтийг өөрийг нь оруулаагүй. х.50 нь зөвхөн «хүүхдэд насны бүлгийг
(1, 5, 10, 15) стандартчилах» тухай хэлэлцүүлэг.

`lib/data/burns/lund-browder.ts` хоосон хэвээр. Өөр эх сурвалж хэрэгтэй.

## 2. Шингэн сэлбэх — х.70–73, Хүснэгт 3

| Томьёо | Найрлага |
|---|---|
| **Паркланд** ✅ | **4 мл/кг/гэмтлийн хувь**, талыг нь эхний 8 цагт |
| Брук | Рингерийн Лактат 1.5 + коллоид 0.5 мл/кг |
| Брукийн (өөрчилсөн) | 2 мл/кг/гэмтлийн хувь |
| Слэйтер | Рингерийн Лактат 2 л/24 ц + шинэхэн хөлдөөсөн плазм 75 мл/кг/24 ц |
| **Гальвестон** ★ | Рингер Лактат + 12.5 г альбумин/л · **5000 мл/м² түлэгдсэн + 2000 мл/м² БГТ** |
| Цинциннати | Эхний 8 ц: Рингер Лактат + NaHCO₃ 50 mEq/л · 4 мл/кг/% + 1500 мл/м² |
| Демлинг | Эхний 8 ц: 2 мл/кг/ц · дараагийн 18 ц: 0.5 мл/кг/ц · шээсний гарц 30 |

**Гальвестон нь хүүхдэд зориулсан** — биеийн гадаргуугийн талбайд (м²)
суурилсан тул хүүхдийн бага жинд Parkland-аас илүү тохиромжтой гэж үздэг.
Хэрэгжүүлэхэд BSA тооцоолол (Mosteller эсвэл DuBois) нэмэх шаардлагатай.

**Хүндийн шалгуур:** 2 дугаар зэргийн түлэгдэл ≥10% БНГТ (х.42).

### ⚠️⚠️ НЭГЖИЙН ЗӨРЧИЛ — ЗААВАЛ ШАЛГАХ

х.249-д Ремифентанилийг **«0.1 мкг/кг/мин»** гэж бичсэн.

## 4. Хүүхдийн онцлог — х.155

### Гальвестон (хүүхдийн үндсэн томьёо)

> «анхдагч шингэн сэлбэлтэнд **5000 мл/м² өдөр + 2000 мл/м² түлэгдсэн
> хэсгийн**… хагасыг **8 цагийн дотор**, дөрөвний нэгийг дараачийн
> **16 цаг тутам**»

Хуваарь: ½ эхний 8 ц · ¼ дараагийн 8 ц · ¼ сүүлийн 8 ц.

БГТ (биеийн гадаргуугийн талбай) тооцоолол хэрэгтэй → Mosteller:
`√(өндөр(см) × жин(кг) / 3600)`. **Өндөр** оролт нэмэх шаардлагатай —
одоогийн `Patient` типэд байхгүй.

### Сайжруулсан Parkland — х.155

> «Энэ томьёогоор **2–4 мл/кг/түлэгдсэн %**»

Муж хэлбэрээр. Одоогийн код 4 гэсэн тогтмол — муж болгож өөрчлөх боломжтой.

### Шээсний гарцын зорилт

| Бүлэг | Зорилт | Эх |
|---|---|---|
| **30 кг-аас бага** | **0.5–1.0 мл/кг/цаг** | х.155 |
| Ерөнхий (насанд хүрэгч) | 30 мл/цаг (Демлинг) | х.72 |
| Олигури | < 0.3 мл/кг/цаг | х.121 |
| Полиури | > 1.0 мл/кг/цаг | х.121 |

Шээсний гарц нь шингэн сэлбэлтийн **гол хяналтын үзүүлэлт** — тооцоолуур
энэ зорилтыг үр дүнтэй хамт харуулах ёстой.

### ⚠️ Шингэн хэтрэлтийн анхааруулга — х.121

> «Шингэний хүргэлт > **250 мл/кг**/24 цаг» (Ivy индекс)

Энэ хязгаарыг давбал хэвлийн хөндийн даралт ихсэх (abdominal compartment
syndrome) эрсдэлтэй. `SafetyLimit` болгож хэрэгжүүлэх ёстой —
Parkland-ын үр дүн энэ хязгаарыг давсан эсэхийг шалгана.

## 5. Электролит — номд БАГА

Энэ ном нь түлэгдэлт/урьдчилан сэргийлэлтийн ном тул электролит засварын
бүрэн томьёо агуулаагүй. Олдсон цорын ганц холбогдох зүйл:

- х.122: «ойролцоогоор **0.5 ммоль/л/кг/% БНГТ** тохируулан **48 цагт** хүргэх»
  — түлэгдэлтийн үеийн натрийн хэрэгцээ байх магадлалтай, контекст тодорхойгүй
- х.339: ийлдсэн дэх натрийн түвшин 135 ммоль/л (лавлагаа утга)

**Дүгнэлт:** Na/K засварын тооцоолуурт **өөр эх сурвалж** хэрэгтэй.
Энэ нь хамгийн өндөр эрсдэлтэй тооцоолол тул хагас мэдээллээр эхлэхгүй.

Санал болгох эх сурвалж: WHO Pocket Book Ch.10 (шингэн, электролит),
RCH Melbourne — Hyponatraemia / Hypernatraemia / Potassium CPG.

## 6. Дараагийн алхам

1. **Гальвестон** хэрэгжүүлэх → BSA тооцоолол (Mosteller) нэмэх
2. **Парацетамол** — одоогийн эмийн файлд түлэгдэлтийн заалт нэмэх
   (х.234–235 эх сурвалжтай)
3. **Lund-Browder A/B/C** — WHO Pocket Book Ch.9 эсвэл RCH-аас
4. **Суфентанил/Ремифентанил** — нэгжийг гуравдагч эх сурвалжаар шалгах
5. **Шээсний гарцын зорилт** + **250 мл/кг Ivy хязгаар** → `SafetyLimit`
6. `Patient` типэд **өндөр** нэмэх (Гальвестон, BSA-д шаардлагатай)
7. Электролит — энэ номд байхгүй, WHO/RCH-аас авах
