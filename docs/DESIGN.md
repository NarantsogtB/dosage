> Кодын дүрмийг `docs/ARCHITECTURE.md`-ээс үзнэ үү.

## 1. Хэнд, юуны тулд

Гар утсаа барьсан эмч, ширээн дээр хүүхэд. Хуудасны **цорын ганц ажил**:
жинг үйлдэл болгон хувиргах, тэр тунд хэр итгэхийг зэрэг харуулах.

Эндээс гарах шийдвэрүүд:

- Гоо сайхан нь **уншилтын хурдны** ард байрлана
- Чимэглэл нь мэдээлэл дамжуулж чадахгүй бол хасагдана
- Анимаци бараг байхгүй — bedside дээр хүлээх цаг байхгүй

## 2. Бичиглэл

| Үүрэг | Фонт | Хаана |
|---|---|---|
| Тэмдэг, ТОО | IBM Plex Mono | Тун, жин, эзэлхүүн, хувь, хугацаа |
| Үндсэн текст | IBM Plex Sans | Бусад бүх зүйл |

**Inter БИШ.** Inter бол бүх вэб дээр байдаг анхдагч сонголт. IBM Plex нь
техникийн баримт бичигт зориулж зохиогдсон, кирилл үсэг бүрэн дэмждэг.

### `.num` класс — аюулгүй байдлын шийдэл

Эмнэлзүйн ач холбогдол бүхий **бүх** тоо `.num` авна:

```css
.num {
  font-family: var(--font-mono);
  font-variant-numeric: tabular-nums;
  font-feature-settings: "zero" 1;
}
```

Яагаад гоо зүйн биш вэ: тэмдэгтийн өргөн тогтмол учир дөрвөн эмийг
дээр дооргүй жагсаахад `2.5` ба `25` хоёр **өөр урттай** харагдана.
10 дахин алдаа нь уншаад биш, ХАРААД илэрнэ. `zero` онцлог нь тэгийг
зураастай болгож `O` үсгээс ялгана.

## 3. Өнгө

Гурван суваг, гурван утга. Өнгө нь чимэглэл БИШ.

| Токен | Утга | Дүрэм |
|---|---|---|
| `--primary` | Үйлдэл, идэвхтэй төлөв | Номин. Хар хөх БИШ. |
| `--destructive` | Эмнэлзүйн аюул | Хэзээ ч чимэглэлээр хэрэглэхгүй |
| `--warning` | Баталгаажаагүй, хязгаарт хүрсэн | Текстэд `--warning-text` |

Дэвсгэр нь номингийн өнгөт өчүүхэн (chroma 0.004) хазайлттай — цэнхэр-
цагаан биш. Карт нь **цэвэр цагаан** тул дэвсгэрээс өргөгдөж харагдана.

### Хэмжсэн харьцаа

Бүх утгыг WCAG-аар тооцоолсон. `--warning` (3.4) нь текстэд тэнцээгүй
тул `--warning-text` (5.6) нэмэгдсэн. Тэмдэг/зураасанд `--warning`
хэвээр — тэдэнд 3:1 хангалттай.

| Хос | Харьцаа |
|---|---|
| foreground / background | 16.7 |
| muted-foreground / card | 5.8 |
| primary-foreground / primary | 6.1 |
| warning-text / warning-muted | 5.6 |
| success-text / success-muted | 6.2 |

## 4. Гарын үсэг — тунгийн зурвас

`components/dosage/DoseBand.tsx`

Хуудасны цорын ганц чанга элемент.

```
▌  362.5 мг   8 ц тутам
▌  НЭГ УДААД · ХОНОГТ НИЙТ 1087.5 мг
```

Зүүн ирмэгийн `3px` зураас нь **нотолгооны түвшин**. Ингэснээр «ямар
тун» ба «хэр итгэх вэ» хоёр НЭГ дүрсэлбэрт нэгдэв — эмч эх сурвалж
хайж доош гүйлгэх шаардлагагүй.

⚠️ Өнгө **хэзээ ч** ганцаараа утга дамжуулахгүй. `SourceFooter` дээр
`EVIDENCE_LABELS`-ийн текст үргэлж давхар бичигдэнэ.

### Юуг хассан бэ

Chanel-ийн дүрэм: гэрээс гарахын өмнө нэг гоёл хас.

- **Картын өнгөт толгой** (`bg-primary/5 border-l-4`) — зурвастай өрсөлдөж
  байсан. Хоёр газар өнгө хэрэглэвэл аль нь чухлыг хэлж чадахаа болино.
- **Стетоскопын дүрс** толгойд — эмнэлгийн клипарт нь энэ
  бүтээгдэхүүний тухай юу ч хэлэхгүй. Домэйн нэр өөрөө Mono-гоор
  бичигдэх нь илүү тодорхой.
- **Түвшин бүрд дүүрэн Badge** — дөрвөн ХЭВИЙН түвшин баталгаажаагүйтэй
  адил чангаар хашгирдаг байв. Одоо зөвхөн «баталгаажаагүй» тасалдуулна.

## 5. Дүрмүүд

1. Шинэ тоо гарвал `.num` заавал авна
2. Шинэ өнгө **нэмэхгүй** — байгаа токеноос сонгоно
3. Өнгө шинээр нэмэх бол WCAG харьцааг нь эхлээд хэмжинэ
   (`scripts/contrast.mjs`)
4. Өнгөөр илэрхийлсэн зүйл бүр текстээр давхар илэрхийлэгдэнэ
5. Нэг дэлгэцэнд нэгээс олон «чанга» элемент байхгүй
