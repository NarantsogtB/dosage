# Тэлэх чадварын үнэлгээ — 2026-10-30

Асуулт: одоогийн бүтцээр 50 → 500 → 5000 эм, 2 → 10+ тооцоолуур руу
тэлж болох уу?

**Дүгнэлт: суурь нь зөв, rewrite хэрэггүй.** 500 эм хүртэл 4 жижиг,
урьдчилан хийх засвартайгаар тэлнэ. 5000 эмд өгөгдөл ачаалах арга, засварлах
хэрэгсэл (admin/DB) өөрчлөгдөнө — engine ба domain өөрчлөгдөхгүй.

## Хэвээр үлдэх хүчтэй тал

| Юу | Яагаад тэлэхэд тустай |
|---|---|
| Data → engine → UI, engine-д `id` салаалалт хориотой | Эм нэмэхэд engine өөрчлөгдөхгүй |
| Эм бүр нэг файл | Git diff цэвэр, DB-д 1 файл = 1 бичлэг |
| Дүрэм тус бүрд `evidenceLevel` + `SourceRef{locator, quotedValue}` | Traceability бүтэцдээ суусан |
| `verified-drugs.test` + `known-gaps.ts` | Эх сурвалжийн чанарыг CI хамгаалж байна |
| Engine-ийн dispatch хүснэгт, complexity 3 | Шинэ basis/cap = нэг файл + нэг мөр |
| `status: active/draft/retired` | Admin-д бэлэн |
| `/dose/[slug]` статик, unverified = `noindex` | 5000 хуудас ч статикаар болно |
