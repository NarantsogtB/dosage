# Decisions

Богино ADR (Architecture Decision Record) маягийн лог. Зорилго нь "яагаад
ингэж хийсэн бэ" гэдгийг дараа дахин олж мэдэхгүйгээр, шууд эндээс уншиж
болохоор байлгах. Chat/session бүрийг бүхэлд нь хадгалахын оронд зөвхөн
**шийдвэр + шалтгаан**-ыг энд бичнэ.

## Загвар (шинэ decision нэмэхдээ хуулж ашиглах)

```
## YYYY-MM-DD — <Богино гарчиг>

**Context:** юу шийдэх шаардлагатай болсон
**Decision:** юу шийдсэн
**Why:** яагаад (өөр сонголтуудыг яагаад авахгүй байсан)
**Status:** accepted / superseded by [[...]]
```

## 2026-11-09 — Эмүүд таб, бүтэн дэлгэцийн хайлт, Тохиргоо (Шат 9d)

**Context:** V4 доод навигац 3 таб (Нүүр · Эмүүд · Тохиргоо), хайлт бүтэн дэлгэц (Figma 123:263, 128:917, 131:1511).
**Decision:**
- **Навигац:** `TABS` (`nav/routes.ts`); тооцоолуурууд нүүрний 4 товчоос. «Яаралтай» нь mobile толгойд байнга (`EmergencyLink`, улаан биш) — 1 товшилт хэвээр.
- **`/drugs`, `/settings`** — client төлөвтэй хуудас, `noindex`, sitemap-д орохгүй; мөлхөх зам нь `/dose`-ийн `DrugIndex` (одоо А–Я үсгээр бүлэглэсэн, холбоос DOM-д хэвээр).
- **Миний эмүүд:** localStorage `dosage.favorites.v1` (эмийн id л — өвчтөний мэдээлэл биш), max 12. Нэмэх/хасах = хайлтын favorite горим.
- **Хайлт:** `SearchOverlay` (Dialog), `openSearch()` event-ээр; `<md`-д `requestSearchFocus` үүнийг нээнэ, `DrugSearch` карт `<md`-д нуугдсан. Эм дарахад идэвхтэй өвчтөнд нэмээд `/dose` руу (`addDrugToActive`). `DRUGS` нь нүүр хуудасны bundle-д орохгүй (`dynamic`).
- **Тохиргоо:** өнгө төрх, жингийн нэгж (`dosage.prefs.v1`, шинэ өвчтөний анхны нэгж), Миний эмүүд, бүх өвчтөнийг устгах (+ Буцаах), нотолгооны шат. **«Хэвлэх» мөр хасагдсан** (A4-с бусад сонголт байхгүй). **Санал хүсэлт** мөр зөвхөн `NEXT_PUBLIC_FEEDBACK_URL` тохируулсан үед харагдана (хаяг зохиоогүй).
**Why:** localStorage-д зөвхөн өвчтөнгүйн тохиргоо; өвчтөний жин/нас sessionStorage хэвээр.
**Status:** accepted. **Нээлттэй:** бүтэн дэлгэцийн хайлтаас өвчнөөр хайж олсон заалтыг (`indicationCode`) урьдчилан сонгохгүй (desktop-д хэвээр); analytics event 9e-тэй хамт.

## 2026-11-09 — Үр дүнгийн «баримт» V4 харагдац (Шат 9c)

**Context:** Figma 123:100 / 130:1234 / 130:1413. `DosageCard`-ийн бүтэц, дараалал хэвээр, зөвхөн харагдац.
**Decision:** Шилэн толгой (`DosageCardHeader` + `DoseBand`), заалт segmented (`ToggleGroup`),
3 tile (`DoseTiles`: давтамж/хугацаа/өдрийн нийт), `MaxDoseMeter`, хэлбэрийн мөр (дүрс tile),
`DisclosureRow` (дүрс + хураангуй), доод pill «Жор хуулах». Figma-тай зөрсөн газар:
- **мг = мл тэнцүү тод** нь `FLAGS.mlFocal`-ийн ард хэвээр (эмнэлзүйн хяналт). Flag унтраалттай үед мл жижиг мөр.
- **Нэг danger:** таслагдсан үед зөвхөн meter улаан; толгойн мөр, «Яаж бодсон бэ?» улаан биш.
- **«Эх сурвалж N ›» дэлгэгдэх мөрийг хийгээгүй:** эх сурвалж үргэлж харагдана (`SourceFooter`). Нотолгооны түвшин + хяналтын огноо шилэн толгой руу шилжсэн (footer-т давхардахгүй).
- **Давтамжийн tile** `FREQUENCY_SHORT`-оос; интервал шинээр тооцоолоогүй.
- **E:** шар мөр нь `EVIDENCE_LABELS.E_unverified` + `Disclaimer`-тэй НЭГ эх өгүүлбэр (`dosage/unverified-note.ts`).
- Толгойн нотолгоо = идэвхтэй ДҮРМИЙН түвшин (өмнө эмийн хамгийн хүчтэй түвшин байв; илүү сайн заалтыг `BetterEvidenceHint` хэлнэ).
- Back/Print толгойн товч, бүтэн дэлгэцийн route хийгээгүй (карт `/dose` дотор).
**Status:** accepted
**Хэмжсэн:** шилэн толгойд тусгай токен нэмээгүй (`bg-card/55`), contrast скрипт өөрчлөгдөөгүй — `card` хос аль хэдийн шалгагддаг.

## 2026-11-04 — `/emergency` өгөгдөл, заалтаар сонгох (Шат 7b)

**Context:** 7a-ийн хоосон хуудсанд эх сурвалжтай мөр нэмэх. Диазепамын таталтын
тун `cns` эмийн файлд байх нь зөв (эм нэг файл), харин хуудас `category:
"emergency"`-гээр шүүдэг байсан.
**Decision:** Эм ангиллаар биш ЗААЛТААР сонгоно (`lib/emergency/emergency-indications.ts`:
cardiac_arrest, anaphylaxis, status_epilepticus, hypoglycaemia); мөр нь заалт × зам
(диазепам IV/IO ба шулуун гэдэс тусдаа). Шинэ давтамж `stat` (нэг удаа, давтаж
болно) — «Өдрийн нийт» харуулахгүй. Эмч баталсан: adrenaline зүрх зогсолт IV/IO
10 мкг/кг (≤1 мг), анафилакси IM 0.01 мг/кг (≤0.3 мг, <12 нас — MSF); glucose 10%
2 мл/кг; diazepam IV/IO 0.3 мг/кг (≤10 мг), PR 0.5 мг/кг (<12 нас ≤10, ≥12 ≤20);
болюс 10/20 мл/кг. Эх сурвалж: MSF Paediatric care 2024, RCH Resuscitation (2025-12),
RCH Hypoglycaemia (2025-08), RCH IV fluids (2026-01), WHO Pocket Book 2013.
Нэг эх сурвалжтай (amiodarone, дефибрилляци, midazolam, ETT) — хоёр дахь олдтол
нэмэхгүй (эмчийн шийдвэр). `/emergency` бүртгэл, nav, sitemap-д орсон.
**Why:** Эмийн тун нэг файлд, хуудас нь өгөгдлөөс (заалт) хамаарна — engine-д
id-гаар салаалахгүй. Замын мөрийг `lib/emergency`-д дүрмийг замаар шүүж engine-ийг
дуудна, engine өөрчлөгдөөгүй.
**Status:** accepted

## 2026-11-04 — IV/IM зам ба нунтаг найруулах (Шат 6)

**Context:** Тарилгын дүрэмтэй эмүүдэд (ceftriaxone, gentamicin) бэлдмэл байхгүй,
бэлдмэл замгүй, нунтаг шилийн загвар алга байв.
**Decision:** Бэлдмэлд `routes` (анхдагч амаар), ампул = `liquid` + `routes`
(тусдаа төрөл биш). Шинэ `powder`: `mgPerVial` + `reconstitutions` (зам, шингэн,
мл, `finalMgPerMl`). Эцсийн концентрацыг ЭХ СУРВАЛЖААС — шилний нунтаг эзэлхүүн
нэмдэг тул шил ÷ шингэн-ээр тооцоолохгүй. Engine бэлдмэлийг дүрмийн замаар шүүж
(`oral_iv` → амаар + IV, `iv_im` → IV + IM), найруулга бүрд мөр, шилний тоо
(⌈дээд тун ÷ шил⌉), trace-д найруулга. Сонголтын түлхүүр `id@зам`. Rx мөрийн
найруулга — `rxFormulation` flag-ийн ард. Хайлтад «Амаар / Тарилга».
**Why:** MSF-ийн ceftriaxone хуудсанд найруулгын эзэлхүүн/концентрац байхгүй —
бодит өгөгдлийг Монголын бүртгэлийн зааврыг эмч баталсны дараа.
**Status:** accepted

## 2026-11-04 — Тунгийн нэгж (S4)

**Context:** Бүх basis/cap/бэлдмэл, engine, текст зөвхөн мг байв; яаралтай тусламж,
IV, электролитод мкг, ЕД, ммоль хэрэгтэй. Мкг↔мг төөрөлдөөн — 10× алдааны эх.
**Decision:** Нэгж нь ДҮРЭМ (`doseUnit`) ба БЭЛДМЭЛ (`strengthUnit`) түвшинд,
анхдагч мг (51 эмийн файл өөрчлөгдөөгүй, талбарын нэр түүхэн хэвээр). Хөрвүүлэлт
зөвхөн масс бүлэгт (`lib/engine/units/convert-unit.ts`); нийцэхгүй бэлдмэлийг
engine алгасаж, тест (`validateUnits`) өгөгдлийн алдааг барина. Format: «0.1 мг
(100 мкг)», «1500 мкг (1.5 мг)». Хурдын тун (`InfusionRateBasis`) — зөвхөн төрөл,
`DosingBasis`-д ороогүй; мг/м² — тусдаа.
**Why:** Өгөгдөл, одоогийн тестийг хөндөхгүйгээр шинэ нэгжийг аюулгүй нэвтрүүлэх.
**Нээлттэй:** `roundVolume` 0.025 мл-ээс бага эзэлхүүнийг 0 болгоно — өтгөн
(ЕД/мкг) бэлдмэлд эмчийн шийдвэр хэрэгтэй.
**Status:** accepted

**Status:** accepted

## 2026-11-04 — Бүлэг 3, 1-р багц: dexamethasone → круп, methylprednisolone хасах

## 2026-11-04 — Бүлэг 2, 3-р багц: ЕХ-ны зохицуулагчийн SmPC (3c); 2 эм хасах

**Context:** Бүлэг 2-ын сүүлийн 4 эм. Diphenhydramine, salbutamol-ийн амаар тун
аль ч эх сурвалжид байхгүй (PCH — судсаар/ингаляци). Acetylcysteine-ийн амаар
салс шингэрүүлэх заалт хүүхдийн эмнэлгийн зааварт байхгүй, гэхдээ Монголд
