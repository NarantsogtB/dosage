# Шат 4 — Өвчин/заалтаар хайх

**Хугацаа:** 1–2 өдөр · **Хамаарал:** S2 · **Унших:** `lib/search/`,
`components/search/` (DrugSearch, SearchResults), `docs/ANALYTICS.md` §3

## Хийх
- «хатгаа», «ДЗХ», «шээсний замын халдвар» → тухайн заалттай эмүүд.
- Заалтын бүртгэл + синонимыг search index-д. Engine рүү орохгүй.
- Үр дүнд аль заалтаар таарсныг харуул; сонгоход тухайн заалт урьдчилан сонгогдоно.
- Нэрээр таарсан нь заалтаар таарснаас дээр.
- `search_no_result` логик хэвээр.
