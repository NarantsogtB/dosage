# Шат S4 — Тунгийн нэгж ба хурд

**Хугацаа:** 2–3 өдөр · Plan mode · **Унших:** `lib/engine/CLAUDE.md`,
`lib/domain/dosing-basis.ts`, `dose-cap.ts`, `formulation.ts`, `lib/format/format-amount.ts`

## Яагаад
Бүх basis/cap/formulation зөвхөн мг. Яаралтай тусламж, infusion, электролит:
мкг, ED (units), ммоль, г, мл/кг; мкг/кг/мин, мг/кг/цаг гэх мэт хурд хэрэгтэй.

## Хийх
- `DoseUnit` төрөл (mg | mcg | g | units | mmol | mL). Basis/cap/formulation-д
  нэгж; **анхдагч mg** тул одоогийн 51 эмийн файл өөрчлөгдөхгүй.
- Engine нэгжийг хольж тооцоолохгүй — нэг дүрэм доторх нэгж нийцэхгүй бол
  validation алдаа. Нэгж хөрвүүлэлт (mg↔mcg↔g) нэг цэвэр модульд.
- Хурдын basis-ийг одоо зөвхөн domain-д тодорхойлох эсэхийг plan-д санал болго
  (хэрэгжүүлэлт infusion шатанд).
- Format: «0.1 мг (100 мкг)» гэх мэт аюулгүй харуулалт — мкг/мг төөрөлдөөнөөс
  сэргийлэх (эмнэлзүйн алдааны түгээмэл эх).

## Шалгуур
Бүх одоогийн тест өөрчлөлтгүй ногоон. Шинэ нэгжийн тест fixture-ээр.
