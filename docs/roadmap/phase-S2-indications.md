# Шат S2 — Заалтын бүртгэл

**Хугацаа:** 1 өдөр · **Унших:** `lib/domain/indication.ts`, `lib/data/labels/`,
`lib/engine/rule/match-indication.ts`

## Яагаад
`indication.code` + `labelMn` дүрэм бүрд чөлөөт текстээр. 500 эмд ижил өвчин
өөр кодтой болж, өвчнөөр хайх (Шат 4), протокол ажиллахгүй.

## Хийх
- `lib/data/labels/indications.ts`: code → labelMn + синонимууд (монгол,
  латин, товчлол — жишээ «хатгаа», «пневмони», «уушгины хатгалгаа»).
- Дүрэм дэх `indication` нь бүртгэлийн code-оор (labelMn-ийг бүртгэлээс
  авах эсвэл тэнцүү эсэхийг тест шалгана — аль нь бага өөрчлөлттэйг сонго).
- Тест: бүртгэлгүй code хориотой.
- Engine-ийн зан төлөв өөрчлөгдөхгүй.
